# CalorieTrack

A clean, responsive, client-side Calorie & Macro Tracker built with pure vanilla HTML, vanilla CSS (no CSS variables, no Tailwind), and vanilla JavaScript.

All data persists locally in the browser via `localStorage` with zero backend dependencies.

## Features

- **Daily Calorie & Macro Tracking**: Real-time circular progress gauge showing consumed vs. remaining calories, with macro breakdowns for Protein, Carbs, and Fats.
- **Date Navigation**: Easily browse, log, or review entries across different days or jump back to Today.
- **Meal Breakdown**: Categorized logs for Breakfast, Lunch, Dinner, and Snacks with subtotals.
- **Quick-Add Presets**: 1-click preset chips for common whole foods and protein sources.
- **Customizable Goals**: Set your own daily calorie and macronutrient targets directly in the app.
- **Zero Dependencies**: Pure HTML5, CSS3, and ES6 JavaScript. No framework, no CSS variables, no backend.

## Getting Started

Simply open `index.html` in any modern web browser:

```bash
open index.html
```

Or serve locally with any static server:

```bash
npx serve .
# or
python3 -m http.server 8000
```
